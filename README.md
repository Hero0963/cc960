# cc960 — 隨機開局象棋

> 借鑑西洋棋 Chess960（Fischer Random）的中國象棋變體：**走法、吃法、勝負規則 100% 不變，只把開局擺法隨機化**。
> 合法開局 **339,484** 種（標準開局也在其中）。

**🎮 線上試玩：<https://hero0963.github.io/cc960/>**（單頁、免安裝、無後端，抽一局就能直接下）

---

## 一句話說明

象棋高手輸贏常常在「誰背的布局定式多」，導致頂尖對局和棋率偏高。
cc960 把**開局擺法隨機抽**，讓背譜失效、第一步就得靠棋力判斷；但走法一步都沒改，
所以你的中局手筋、殘局知識、甚至棋盤棋子都完全沿用。

用一句類比：**同一副棋、同一套規則，只是開場不再只有一種**。

## 為什麼要做

| 事實 | 數字 |
|------|------|
| 2020 象甲上海隊常規賽和棋率 | 88 局中 59 和 ≈ **67%** |
| 2003–2006 四屆象甲「定式和棋」占比 | 約 **1/3** |
| 對照組：Chess960 賽事分勝負率 | Freestyle 2025 **54%** vs 傳統開局 Candidates 2024 **45%** |

成因是棋界共識：**布局定式成熟**（背譜即可進入和局軌道）＋兌子簡化後守和門檻低。
完整的問題數據、他山之石（揭棋／貼時／加大棋盤／將棋持駒）比較與取捨理由 → **[docs/rationale.md](docs/rationale.md)**。

## 擺法規則（全部只有 6 條）

1. **走法與勝負規則完全同標準象棋**，只有初始擺放不同。
2. **紅黑點對稱**：黑方擺法＝紅方旋轉 180°（紅 (r,c) ↔ 黑 (9−r, 8−c)）。
   *從各自座位看，雙方陣形一模一樣*——紅「一路」兵進，對應黑「1路」卒進（不是同一直線）。
3. **將帥居中路九宮底線，雙士貼於兩側**（中路自對稱；中路必有兵卒相隔，永不照面）。
4. **象 2 子**隨機置於「原軌道」7 點中任 2 點：底線 c/g、宮頂線 a/e/i、河沿 c/g。象離開底線時，該底線位留空。
5. **馬 2 子、車 2 子**隨機分配剩餘的底線非九宮路；**炮 2 子**隨機置於宮頂線任 2 路（不可疊上象）。
6. **兵 5 子**各路獨立：原位或前進一格（不可疊上河沿象）。

再加一道**首著靜置檢定**，剔除「開局就能白吃大子」的失衡局面：任一方的任一首著吃子，必須「有根且不虧」或「對稱可回應」，否則該局面不列入合法池。

> 為什麼象只能放那 7 點、兵只能進一格？**「預走合法步」原則**：所有起始位置都必須是「開局前在己方領土走原本合法步」可以到達的點。變的是出發陣形，不變的是每個子的本性——所以棋味與殘局知識完整保留。

## 關鍵數字

| 項目 | 數值 |
|------|------|
| 編號空間 | 1,389,312 |
| **合法開局** | **339,484**（約 24%；標準開局＝編號 **3872**） |
| 輕量版（象、兵固定，只隨機車馬炮） | **216** 局，全數合法（標準開局＝ #122） |
| 軸對稱版（每方自身以中線左右對稱） | **146** 局（標準開局＝ #21） |
| 紅方首著機動力 | 19–53 著，平均 36.7（標準開局 44 著） |
| 局面特徵 | 90.2% 含進兵、99.0% 含高位象 |

三種池都做在同一頁的下拉選單裡：**完整版**最刺激、**軸對稱版**棋形最像標準棋（新手友善）、**輕量版**編號最好記（適合當比賽用池）。

## 開發

無執行期相依；只有測試需要 jsdom。

```bash
npm install       # 只裝 jsdom（測試用）
npm run build     # src/ → docs/index.html（單檔演示頁）
npm test          # build ＋ 16 項無頭 DOM 迴歸測試
npm run count     # 全空間枚舉，重算合法局面數（約 25 秒，改規則後必跑）
npm run stats     # 特徵統計＋終端機渲染示範局面
```

```
src/rules.js      象棋走法引擎（與隨機開局無關，就是一副普通象棋）
src/setup.js      隨機開局擺位產生器＋編號系統＋首著靜置檢定
src/ui.js         演示頁互動（棋盤 SVG、走子、三池切換）
src/shell.html    演示頁外殼（HTML/CSS/文案，含三個注入點）
scripts/build.js  組裝：shell ＋ 三個 js 內聯 → docs/index.html
docs/index.html   建置產物（GitHub Pages 直接吃這個檔；請勿手改）
```

`docs/index.html` 是**建置產物**：要改演示頁請改 `src/`，再 `npm run build`。

## 現況與後續

**現況**：規格 v3 定案、演示可玩、16 項測試全過。尚未量測先手優勢分布，尚未實測和棋率，未實作長打（長將、長捉）判例。

**Roadmap**（完整版含 done 條件與已定案決策 → [docs/roadmap.md](docs/roadmap.md)）

1. 引擎審局：用 Pikafish 評估合法局面的先手優勢分布，產出接近平衡的「競賽池」。
2. 實戰試玩：抽局自戰／找棋友對弈，主觀評估新鮮度與守和難度。
3. v4 研究：將位隨機（點對稱架構下已可行）、士的宮內異位、檢定改用引擎靜態評估。
4. 線上對弈版＋簡單 AI。

## 原創性聲明

查證當下（2026-07）於 chessvariants.com、維基百科象棋變體列表與中英文圈搜尋，**未見「明置隨機開局」的象棋變體實作**。
與**揭棋**的差異：揭棋是暗子隨機（有隱藏資訊與運氣成分），cc960 是**明置隨機**——雙方開局前就看得見全部棋子，**零運氣成分**，只是不知道會抽到哪一局。
